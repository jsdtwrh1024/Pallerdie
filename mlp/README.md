# MLP 训练实验室

一个纯 JavaScript 的多层感知机实现与可视化。没有框架、没有依赖、不需要服务器，
双击 `index.html` 就能跑。

## 文件分工

```
mlp-lab/
├── index.html      页面结构
├── mlp.css         样式
└── js/
    ├── nn.js       ★ 实现：前向传播、交叉熵、反向传播、参数更新（不碰 DOM）
    └── app.js      可视化：决策边界、损失曲线、权重热力图、网络结构、单步解剖
```

把 `nn.js` 和 `app.js` 分开是刻意的：前者是纯数学，后者是纯绘制。
报告里贴代码贴 `nn.js`，演示贴 `app.js`，两件事互不混淆。

## 核心实现（`js/nn.js`）

网络结构由 `sizes` 数组决定，例如 `[2, 8, 8, 3]`：

- **前向传播** `forward(x, keep)`
  `z[l] = W[l] · a[l-1] + b[l]`，`a[l] = f(z[l])`。最后一层不激活，交给 softmax。

- **损失** 交叉熵 `L = -ln p[y]`，softmax 里先减最大值防溢出。

- **反向传播** `backward(a, z, y)`
  softmax + 交叉熵的梯度恰好是 `p - onehot(y)`，输出层不用再乘一次导数。
  逐层往回传：`δ[l-1] = (W[l]ᵀ · δ[l]) ⊙ f'(z[l-1])`，
  `dW[l][j][i] = δ[l][j] · a[l-1][i]`。

- **参数更新** `step(batch, lr)`
  `W ← W − lr · (1/n) Σ dW`，梯度在 batch 内累加后统一更新。

- **梯度正确性**：用中心差分做过数值校验，`dW` 与数值梯度的最大误差约 `1e-10`。

## 可视化的四个视图

| 视图 | 画的是什么 | 对应哪个概念 |
| --- | --- | --- |
| 决策边界 | 画布上每个像素做一次前向，按 argmax 上色 | 模型当前学到的函数 |
| 损失曲线 | 每个 epoch 的全量交叉熵 | 优化是否在推进 |
| 权重热力图 | 某一层 `W` 的正负与大小 | 参数本身怎么变 |
| 网络结构 | 每条边的颜色和粗细 = 权重正负与绝对值 | 参数与拓扑的关系 |

决策边界用 `ImageData` 在 56×56 上算完再放大绘制，边缘自然过渡；
为了不在一帧里分配几千个数组，`fastPredict` 复用了预分配缓冲。

## 单步解剖

点画布上任意一个点，会显示这个样本的：

- 输入 `x`、真实类别、预测类别、交叉熵
- 每个隐藏层的激活值 `a = f(z)`
- 输出层 `δ = p − onehot(y)`
- 一个具体的乘法：`Δw = δ × a = ?`，以及 `W ← W − lr × Δw`

这一块是"实现"的证明：能对着屏幕讲清反向传播到底算出了什么。

## 数据

三类螺旋，每类 100 个点，噪声 0.05。选螺旋不选团块的原因：团块用单层线性模型就能分开，
看不出隐藏层的作用；螺旋必须靠多层非线性才能切开，"调神经元数"这个操作才有肉眼可见的结果。

## 五个可以现场演示的对照

| 操作 | 结果 | 说明 |
| --- | --- | --- |
| 默认 `8×8` + ReLU + lr 0.1 | 400 epoch 内到 100% | 正常收敛 |
| 学习率 0.5 以上 | 损失卡在 1.1 抖动，不再下降 | 步子太大，跨过最低点 |
| 隐藏层 1 降到 2、隐藏层 2 设为「无」 | 约 45%，边界只剩两段折线 | 容量不足 |
| 激活换成 sigmoid | 约 36% | 导数最大 0.25，梯度逐层衰减 |
| 初始化选「全零」 | 约 33%，损失不降 | 同层神经元梯度完全相同，对称性破不掉 |

（以上数字是 400 epoch、batch 16 下测的，每次运行会有几个点的波动）
